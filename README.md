# needs-woman40-lp2

プライベートジムNeeDS（株式会社NeeDS）の、Meta広告用ランディングページ。

既存の `women40`（[needs-golf-lp](https://github.com/nakatsukasa111-tech/needs-golf-lp) リポジトリ）に対する
**A/Bテスト用のバリエーション**を管理します。既存LPはそのまま残し、こちらで訴求違いを検証します。

| ディレクトリ | 内容 |
|---|---|
| [`women-v2/`](women-v2/) | 40代・50代・60代女性向けLP v2「好きなことを、これからも楽しめる身体へ。」 |

デザイン（カラー変数・フォント・余白設計・セクションの型・CTAブロック）は `women40` から
一切変更せずに引き継いでいます。詳細は [`women-v2/README.md`](women-v2/README.md) を参照してください。

GitHub Pagesで公開する場合、LPのURLは `/women-v2/` になります。
