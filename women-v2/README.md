# NeeDS 40〜60代女性向けLP v2（`women-v2/`）

プライベートジムNeeDS（株式会社NeeDS）の、**40代・50代・60代女性向け**集客ランディングページ。
既存の `women40`（`needs-golf-lp/women40/`）を複製し、**カラー変数とフォントは引き継いだまま、コピー・セクション構成・レイアウトを参考LPに寄せた**A/Bテスト用のバリエーションです。

## ファイル

| パス | 内容 |

## デザインについて

**カラー変数とフォントは `women40` から変更していません。**
`<style>` 内の既存CSSブロックは1文字も書き換えておらず、v2で追加したCSSは
末尾の `v2 additions` ブロックにまとめてあります。追加分も既存の変数
（`--navy` / `--cta` / `--paper-2` / `--line` / `--gold-soft` など）と
3書体（`Noto Sans JP` / `Noto Serif JP` / `Cormorant Garamond`）だけで組んでいます。
**新しい色・書体は一切追加していません。**

一方で**レイアウトの組み方は参考LPに合わせて作り替えています**。
`women40` の「左揃え・余白の広いエディトリアル」から、

## 訴求の軸

**「好きなことを、これからも楽しめる身体へ。」**

体重や見た目の数字ではなく、**好きなことを続けられる身体**を軸に据えています。

- ターゲット：40代・50代・60代の女性（`women40` から60代まで対象を拡大）
- 想定読者：運動習慣がないまま今の年代を迎えた方。Meta広告からの初訪問（NeeDSを知らない方）
- 安心材料：理学療法士・アスレティックトレーナーが在籍／完全個室・マンツーマン／
  指導実績15年以上・リピート率90%以上・平均継続年数3年以上
- CTA：公式LINE登録 → 無料体験予約（`https://lin.ee/WEFp411`）
- 計測：GTM `GTM-P95C26ZR`。CTAクリック時に `cta_click` を送信
  （`cta_position` は `header` / `hero` / `reason` / `trial` / `footer` / `sticky`）
- `noindex,nofollow`（広告専用ページのため検索インデックス不要）

### 意図的に載せていないもの

- ボディメイク大会・コンテスト系の訴求
- ビフォーアフター写真、体重の数字を煽る表現
- 「プロも通う」訴求の写真グリッド（本文中の1〜2行に圧縮）

### 長さの圧縮について

改修前は**スマホ17.6画面**あり、1セクションが2画面を超えるものが複数ありました。
セクションを12→8に統合し、余白と要素数を詰めて**約53%短縮**しています。

| 統合前 | 統合後 |
|---|---|
| プロも通う ／ 続かない壁 ／ 選ばれる理由 | → **初めてでも大丈夫**（3.（不安→安心）を1画面に） |
| こんな未来 ／ 実績 | → **実績と、目指せる未来** |

要素数も削っています：未来 6→4項目、FAQ 6→4問、続かない壁 4→3項目。

スマホでの主な圧縮策：トレーナー3名と店舗2つを**横並び**に、
無料体験の3ステップを**写真左・テキスト右の横型カード**に、

### 「あなた専用プラン」について

セクション4に統合し、見出しを**「あなただけの身体づくり計画をプレゼント！」**、
サブを**「何を・どれくらい・どう続けるか」が分かる、あなた専用プランをお渡しします。**としています。

具体的な頻度・期間（週◯回×◯ヶ月）は実運用の数字が未確定のため記載せず、
カード下の1行で「何を＝あなたに合う種目とメニュー／どれくらい＝通う頻度と期間の目安／
どう続けるか＝無理のない進め方」とだけ示しています。事実と齟齬が出ない構成です。
実際の目安が決まり次第、数字を入れた表に差し替えられます。

CTAは **ヒーロー ／ 無料体験 ／ 料金 ／ 最終CTA ／ フッター** の5箇所。
これに加えてヘッダーのミニCTAと、スマホ用の追従フッターCTAがあります
（`cta_position` は `header` / `hero` / `trial` / `price` / `last` / `footer` / `sticky`）。
