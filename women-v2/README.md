# NeeDS 40〜60代女性向けLP v2（`women-v2/`）

プライベートジムNeeDS（株式会社NeeDS）の、**40代・50代・60代女性向け**集客ランディングページ。
既存の `women40`（`needs-golf-lp/women40/`）を複製し、**デザイン資産はそのままに、コピーとセクション構成のみを差し替えた**A/Bテスト用のバリエーションです。

## ファイル

| パス | 内容 |
|---|---|
| `index.html` | LP本体。CSS・JSを内包した単体HTML。外部依存はGoogle FontsとGTMのみ |
| `images/` | 写真・ロゴ。`women40/images/` からそのまま流用 |

## デザインについて（重要）

`women40` の `<style>` ブロックは**1文字も変更していません**。
カラー変数・フォント・余白設計・セクション見出しの型（英字ラベル＋日本語小見出し）・
CTAブロック・追従フッターCTAは、すべて既存のものをそのまま引き継いでいます。

v2で追加したCSSは `<style>` 末尾の `v2 additions` ブロックにまとめてあり、
いずれも既存のカラー変数（`--navy` / `--cta` / `--paper-2` / `--line` / `--gold-soft` など）と
2書体構成（`Noto Sans JP` / `Noto Serif JP` / `Cormorant Garamond`）のみで組んでいます。
**新しい色・書体は一切追加していません。**

| 追加クラス | 用途 |
|---|---|
| `.check-list` / `.ck` | Future のチェックリスト6項目 |
| `.step-list` | Wall の4つの壁 ／ Free Trial の3ステップ（濃色ブロック内） |
| `.reason-list` | Reason の4項目 |
| `.quote-box` | Reason の囲みメッセージ |
| `.side-box` | Free Trial の「無料体験はここまでわかる」 |
| `.studio-grid` / `.env-list` / `.price-box` | Studio の通いやすさ・料金 |
| `.ph-box` | 写真の仮置きプレースホルダー |
| `.pillars-light` | 既存 `.pillars` を明るい背景でも使うための色の上書き |

## 訴求の軸

**「好きなことを、これからも楽しめる身体へ。」**

体重や見た目の数字ではなく、**好きなことを続けられる身体**を軸に据えています。

- ターゲット：40代・50代・60代の女性（`women40` から60代まで対象を拡大）
- 想定読者：運動習慣がないまま今の年代を迎えた方。Meta広告からの初訪問（NeeDSを知らない方）
- 安心材料：理学療法士・アスレティックトレーナーが在籍／完全個室・マンツーマン／
  指導実績15年以上・リピート率90%以上・平均継続年数3年以上
- CTA：公式LINE登録 → 無料体験予約（`https://lin.ee/WEFp411`）
- 計測：GTM `GTM-P95C26ZR`。CTAクリック時に `cta_click` を送信
  （`cta_position` は `header` / `hero` / `reason` / `trial` / `footer` / `sticky`）
- `noindex,nofollow`（広告専用ページのため検索インデックス不要）

### 意図的に載せていないもの

- ボディメイク大会・コンテスト系の訴求
- ビフォーアフター写真、体重の数字を煽る表現
- 「プロも通う」訴求の写真グリッド（本文中の1〜2行に圧縮）

- **Studio セクションの写真**：`[PHOTO: お客様専用駐車場／館内の様子]` のプレースホルダーで仮置き。
  お写真をご用意でき次第、`<div class="ph-box r-wide">…</div>` を
  `<img class="photo r-wide" src="images/xxx.jpg" alt="（日本語で内容）" …>` に差し替えてください。

  「女性トレーナーが在籍している」ことは、セクション冒頭の1行と2人目の肩書きで示しています。
